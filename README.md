# O EcoSwap é um site em PHP, CSS e JavaScript criado para incentivar a sustentabilidade universitária, permitindo que alunos troquem, vendam ou doem objetos reutilizados (upcycled).

🧩 Funcionalidades

Listagem de produtos com busca e filtro.

Página de detalhes com formulário de contato.

Painel de adição de itens (demo).

Layout limpo e responsivo.

🖥️ Tecnologias

PHP, HTML5, CSS3, JavaScript, Flexbox/Grid.

⚙️ Como executar

Extraia o projeto.

No terminal, execute:

php -S localhost:8000


Acesse: http://localhost:8000

📁 Estrutura
index.php       → Página inicial  
product.php     → Detalhes  
admin.php       → Adicionar item  
products.php    → Dados (array PHP)  
styles.css      → Estilo  
script.js       → Interações JS
